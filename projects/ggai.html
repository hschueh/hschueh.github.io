The game

A single-player text adventure. You type anything you want to do, from Discord or the web, and an AI agent plays game master: it reads the world, rolls dice, narrates the outcome and records what changed. Worlds are templates, from Jin Yong wuxia to cyberpunk Taipei, and new places and characters are generated as you reach them.

How it's built

The hard part of an AI game is keeping the model consistent. Here the model only tells the story. It changes the world through typed tool calls, every response is checked against a schema, and the world itself is plain Markdown and JSON files that I can read and fix by hand.
