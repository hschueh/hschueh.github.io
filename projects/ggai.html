The games

GGAI: a text RPG that remembers

A single-player text adventure. You type anything you want to do, from Discord or the web, and an AI agent plays game master: it reads the world, rolls dice, narrates the outcome and records what changed. Worlds are templates, from Jin Yong wuxia to cyberpunk Taipei, and new places and characters are generated as you reach them. Play the alpha ↗

Horde • Taipei: players are the zombies

A multiplayer zombie apocalypse in one shared Taipei. Every player controls a single zombie; the AI plays the eight survivors trying to get out of the city. The world moves on a clock, one half-day per hour, so it's a game you check in on rather than sit at. You give your zombie an instinct (who it was before it died), a one-off urge for the next half-day, or whisper an event into the world, and the GM agent works it all into the story. Survivors make their own plans, new ways out can open mid-season, and nobody's ending is written in advance. Each season leaves scars on the map that the next one inherits. Play Horde ↗

How it's built

The hard part of an AI game is keeping the model consistent. In both games the model is an agent with tools, not a single prompt. Each turn it starts from a short briefing, decides for itself whose files and memories to read, rolls dice, and writes its rulings through typed tool calls. Every write is checked against a Zod schema, and the game rules live in plain code rather than in the prompt: movement, defences, hunger and who escapes are settled by a deterministic resolver. The agent's drafts are dry-run through that resolver as it works, so its narration always matches what the rules actually decided.

Memory is modelled on how people remember. Every character, place and player has a profile (what's true now), a memory file (facts that will matter later) and a journal (what happened). The agent wakes up each turn knowing nothing and carries continuity forward only through notes it chooses to write. All of it is Markdown and JSON on disk, so I can read and fix the world by hand.

Horde adds a public GM view: a live trace of every tool call, dice roll and the agent's reasoning before each step, with plans that got overturned by a bad roll or a rule flagged in red. Models are routed through OpenRouter with per-game fallbacks, and shared packages handle the AI layer, login (Google, Discord, email) and logging across games.
