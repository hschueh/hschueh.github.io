GGAI

An AI-native game monorepo: LLM-driven text adventures and life-sims with Discord and web UIs.

What it is

GGAI is a workspace of AI-driven games and the shared libraries that power them. It currently hosts two games, both played in Traditional Chinese: GGAI MUD, a single-player turn-based text adventure with an LLM-driven narrative that you can play from Discord or a web UI, and Mountain Road Monkey, a 30-day Taiwanese motorcycle life-sim presented as a phone UI in Next.js, complete with LLM-narrated mountain runs and LINE-style messages.

How it's built

The monorepo is managed with Turborepo: games depend on shared packages for structured logging and an AI layer that wraps the AI SDK, loads prompts, and parses LLM output through Zod schemas so the games can trust what the model returns. A few deliberate constraints keep it simple — no database (game state lives as markdown and JSON on the file system), strict TypeScript with ES modules everywhere, and models served through OpenRouter so each game picks its own model via config.

Each game deploys independently to a VPS under PM2, so shipping one game never touches the other.
